# Titanic Passenger Data Analytics
## SWYNEX Task 4 – Final Data Analytics Project

### Project Overview
This project analyzes Titanic passenger data by combining data cleaning, exploratory data analysis (EDA), visualizations, and an interactive dashboard.

### Project Objectives
- Prepare and organize the passenger dataset.
- Explore passenger characteristics and survival outcomes.
- Visualize important patterns in the data.
- Present the analysis through an interactive dashboard.

### Tools and Technologies
- Python
- Pandas
- Matplotlib and Seaborn
- Jupyter Notebook
- Streamlit

### Project Structure
- `data/` – Cleaned Titanic dataset
- `notebook/` – Exploratory data analysis notebook
- `charts/` – EDA chart images
- `screenshots/` – Project screenshots
- `app.py` – Interactive dashboard application
- `requirements.txt` – Python package requirements

### Analysis Performed
The analysis explores passenger survival, sex, passenger class, age distribution, fare distribution, and embarkation port.

### How to Run the Dashboard
1. Install Python.
2. Open Command Prompt inside the project folder.
3. Install the required packages:

   `python -m pip install -r requirements.txt`

4. Start the dashboard:

   `python -m streamlit run app.py`

5. Open the local URL shown in Command Prompt.
